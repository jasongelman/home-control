Key Design Decisions

Small Widget

Stacked layout — two action buttons + mic. Tapping an action executes immediately via AppIntent. Mic opens inline voice input.

Medium Widget

Side-by-side actions with more detail (subtitle showing device count or target level). Wider mic bar with prompt text. Shows current time bucket.
