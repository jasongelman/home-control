3rd Slot Logic

Default: 3rd recommendation

When no appliances are running, shows the third-ranked action from the recommendation engine. Same style as the other two slots.

Override: Appliance countdown

When a dishwasher, washer, or dryer is running, the 3rd slot shows the appliance name + remaining time. Slightly dimmer text to visually distinguish it from tappable actions. If multiple appliances are running, shows the one finishing soonest.
